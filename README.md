# Лабораторная работа 8

Приложение на PHP и MySQL для просмотра температуры, управления реле и записи действий пользователя в журнал.

[Открыть сайт](https://forma-anastasia.page.gd/lab8/public/login.php)

Учебный вход: `nastya`, пароль `Demo_251361!`.

## Файлы

- `public` — страницы сайта и стили.
- `app` — подключение к БД, обработка запросов и шаблоны.
- `sql/schema.sql` — таблицы, представление и два триггера.
- `config/local.example.php` — пример настроек подключения.
- `bin` — заполнение учебных данных и симулятор устройства.
- `var` — данные для локального запуска, не публикуемые в Git.

## Локальный запуск

Нужны PHP 8.1+ с PDO MySQL и MySQL 8.0.16+.

1. Создать пустую базу `lab8_iot` с кодировкой `utf8mb4` и импортировать `sql/schema.sql`.
2. Скопировать `config/local.example.php` в `config/local.php` и указать реквизиты MySQL с правами на эту учебную базу.
3. В папке проекта выполнить `php bin/seed.php`, затем `php -S 127.0.0.1:8080 -t public`.
4. Открыть `http://127.0.0.1:8080/login.php`.

Пример отправки показаний: `php bin/simulator.php http://127.0.0.1:8080 1 216 0` — 21,6 °C, реле выключено.

В репозитории ограничения обращений реализованы SQL-триггерами. На бесплатном хостинге InfinityFree они недоступны, поэтому на сайте эти проверки выполняет PHP.
